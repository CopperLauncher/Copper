# Политика конфиденциальности CopperLauncher
1. это приложение не отправляет никаких данных и использует интернет только для скачивание контента для игры
2. Это приложение не собирает никаких данных во время игры
3. После краша игры в лоах сохраняются некоторые данные, но они не передаются разработчику или кому то ещё
4. Copper Launcher предоставляет возможность по вашему одобрению передавать ваши логи стороннему сервису (https://mclo.gs/). После передачи мы не контролируем эти данные.
5. Разработчики CopperLauncher оставляют за собой право обновлять данную политику конфиденциальности без предварительного уведомления
